# 排版规格书 — 三轨参数包矩阵（文书编辑纪律 v7.0 配套）

> **定位**：SKILL.md §2.16 的执行细则。识别轨道（§1.1）→ 查本表取完整参数包 → officecli 一次全量应用。
> **原则**：每轨参数唯一确定，无"或"选项；officecli 为唯一执行工具（禁止 python-docx 修改，仅可只读审查）。

---

## 一、三轨总览

| 轨道 | 文档类型 | 颜色体系 | 适用字体方案 |
|------|---------|---------|-------------|
| A 轨·诉讼 | 起诉状/答辩状/上诉状/代理词/辩护词/证据目录/诉讼类申请书/庭审提纲 | 黑白单色 | 法院版方案B / 客户版方案A |
| B 轨·非诉严肃 | 律师函、法律意见书（正式出具） | 黑白（律所信头） | 方案A |
| C 轨·非诉商务 | 法律备忘录/法律分析报告/服务方案/尽调报告/商务汇报 | **藏蓝 #1A3A5C 强制** | 方案A + 招股书标题规格 |

## 二、A 轨·诉讼（法院版 / 客户版）

### A-法院版（提交法院/仲裁庭）

| 参数 | 值 | officecli 命令 |
|------|-----|---------------|
| 纸张 | A4（210×297mm） | create 默认 |
| 页边距 | 上 3.7 / 下 3.5 / 左 2.8 / 右 2.6cm | `set /section[1] --prop marginTop=3.7cm --prop marginBottom=3.5cm --prop marginLeft=2.8cm --prop marginRight=2.6cm` |
| 文书名称 | 宋体 二号 22pt 加粗 居中 | `add /body --type paragraph --prop text="民 事 起 诉 状" --prop font.ea=宋体 --prop font.latin="Times New Roman" --prop size=22pt --prop bold=true --prop align=center` |
| 一级标题 | 宋体 小四 12pt 加粗 顶格 | `--prop font.ea=宋体 --prop size=12pt --prop bold=true` |
| 正文 | 仿宋 小四 12pt | `--prop font.ea=仿宋 --prop size=12pt --prop align=both --prop firstLineChars=200` |
| 英文/数字 | Times New Roman（所有 run 的 ascii/hAnsi） | `--prop font.latin="Times New Roman"` |
| 行距 | 固定值 28 磅 | `--prop lineSpacing=28pt`（或 lineRule=exact） |
| 首行缩进 | 2 字符 | `--prop firstLineChars=200` |
| 对齐 | 两端对齐 | `--prop align=both` |
| 页码 | 书刊式 — N —，TNR 10.5pt，单右双左 | 分节奇偶页脚 + PAGE 域（见 batch 模板） |
| 页眉 | 律所信头/法院版规范 | `add / --type header` |
| 强调色 | **无** | — |

### A-客户版（发给客户的诉讼文件草稿）

| 参数 | 值 |
|------|-----|
| 页边距 | 2.2 / 2.2 / 2.4 / 2.4cm |
| 主标题 | 黑体 小二号 18pt 加粗 居中 |
| 标题 | 黑体 小四 12pt 加粗 |
| 正文 | 宋体 小四 12pt |
| 行距 | 1.5 倍（`--prop lineSpacing=1.5`） |
| 其余 | 与 A-法院版相同（黑白、书刊式页码） |

## 四、C 轨·非诉商务（Memo / 分析报告 / 服务方案）— 藏蓝强调色

### 基础参数（同 B 轨骨架）

| 参数 | 值 |
|------|-----|
| 页边距 | 2.2 / 2.2 / 2.4 / 2.4cm |
| 正文 | 宋体 小四 12pt，1.5 倍行距，首行缩进 2 字符，两端对齐 |
| 标题规格 | 一级标题黑体三号 16pt、二级黑体四号 14pt、三级黑体小四 12pt（招股书规格）；各级标题段落间距一致（一级段前 14pt 段后 8pt，二级段前 8pt 段后 4pt） |
| 编号体系 | 非诉编号 1. / 1.1 / 1.1.1 |
| 页码 | 书刊式 — N —（TNR 10.5pt） |

### 藏蓝强调色（强制）

| 元素 | 规范 | officecli 语法 |
|------|------|----------------|
| 色板 | 主色藏蓝 `#1A3A5C`；表头底 `#E8ECF2`；斑马纹 `#F5F7FA` | — |
| 一级标题文字 | 藏蓝 #1A3A5C 加粗（二级及以下黑色加粗） | run `"color":"1A3A5C"` |
| 表头 | **唯一默认**：浅藏蓝底 `#E8ECF2` + 藏蓝字加粗（客户明确要求深蓝底白字才启用备选） | cell `"shading":"E8ECF2"` |
| 斑马纹 | **默认不使用**；仅客户明确要求时启用 `#F5F7FA` | cell `"shading":"F5F7FA"` |
| 页眉分隔线 | 藏蓝 0.5pt 单线 | 段落底边框 `"pBdr":"single,1A3A5C"` |
| 强调色范围 | 仅一级标题+表头+页眉线三类元素；正文 100% 黑色；页码/表格边框黑色 | — |
| 无彩降级 | 打印/传真时降为黑色+加粗/下划线 | — |

```json
  {"command":"add","parent":"/body/tbl[1]/tr[2]/tc[1]/p[1]","type":"run","props":{"text":"数据","font.ea":"宋体","font.latin":"Times New Roman","size":"10.5pt"}},
  {"command":"set","path":"/body/tbl[1]/tr[2]","props":{"shading":"F5F7FA"}}

```

### C 轨一级标题示例（藏蓝文字）

```json
[
  {"command":"add","parent":"/body","type":"paragraph","props":{"text":"1. 执行摘要","font.ea":"黑体","font.latin":"Times New Roman","size":"16pt","bold":"true","color":"1A3A5C","align":"both","spaceBefore":14,"spaceAfter":8}}
```

> ⚠️ **构建前最小验证**：`color`/`shading`/`pBdr` 的 props 名以 officecli v1.0.143 实测为准（`officecli help add`），最小测试文档先验证再批量。

## 五、通用执行流程（officecli 新建文档）

```
① 最小验证（≤5 条指令，独立临时文件）→ 确认 props 语法
② 按轨道查本表 → 生成完整 batch JSON
③ officecli create 目标.docx → batch → set 页边距 → add header/footer → save
④ officecli validate + view issues + 双引擎核验（audit_docx.py）→ WPS 打开核对
```

**关键命令速查**：

```bash
# 法院版页边距（A轨）
officecli set out.docx /section[1] --prop marginTop=3.7cm --prop marginBottom=3.5cm --prop marginLeft=2.8cm --prop marginRight=2.6cm

# 客户版页边距（B/C轨、A轨客户版）
officecli set out.docx /section[1] --prop marginTop=2.2cm --prop marginBottom=2.2cm --prop marginLeft=2.4cm --prop marginRight=2.4cm

# C轨一级标题藏蓝
officecli add out.docx /body --type paragraph --prop text="1. 执行摘要" --prop font.ea=黑体 --prop font.latin="Times New Roman" --prop size=16pt --prop bold=true --prop color=1A3A5C

# 表格表头底纹
officecli set out.docx /body/tbl[1]/tr[1] --prop shading=E8ECF2
```
