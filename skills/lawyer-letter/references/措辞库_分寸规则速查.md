# 措辞库 — 分寸规则速查卡（十二条对应）

> §4 十二条规则的「禁用 → 推荐」对照 + 三件套标准原文 + 模糊表述/豁免条款/不减损权利/禁止性语言。起草时逐条对照，审查时逐条打勾。

## 一、定性降险对照表

| 场景 | ❌ 禁用/高风险 | ✅ 推荐 |
|------|--------------|--------|
| 合同未约定验收期限 | 逾期验收、拒绝验收 | 未及时办理验收确认 / 未在本函期限内完成验收确认 |
| 付款迟延（无约定违约金） | 逾期付款、恶意拖欠 | 未按约付款 / 尚有 XX 元未按合同约定支付 |
| 泛指兜底 | 其他违约行为 | 其他不当履行行为 |
| 侵权事实（未经裁判） | 恶意侵权、盗版、剽窃 | 未经许可使用 / 未经授权实施 XX 行为（有生效判决支持的除外，且引用判决须准确完整） |
| 对方动机 | 蓄意、恶意、欺诈 | 不评价动机，只陈述行为与后果 |
| 否定性事实 | 本函不表述为贵司已完成签章验收（元叙述绕弯） | 现有材料证明贵司尚未完成项目签章验收（正面句式） |
| 未经裁判事实 | XX 构成违约（绝对化结论） | 区分「委托人主张」与「法律认定」；争议事实用「据目前了解/据委托人陈述」 |
| 侵权定性（对外函件） | 「抄袭」「侵犯著作权」「已被判决侵权」（未经生效判决支持） | 「涉嫌侵权」；引用既往判决必须准确完整，不得包装败诉/未决事项 |

## 二、事实限定语（硬性句式）

- 事实节标题固定：**「一、相关事实」**（上海指引第 12 条）
- 事实节首句固定：**「根据委托人向本所提供的上述事实及证据，本所认为：」**
- 待核验事项就地标注：「（XX 材料待补充核验）」，不得写成既成事实
- **证据不充分豁免条款**：除限定语外可加「**以上事实正在进一步调查取证中**」（上海律协 2021 指引第 10.2 条）
- **模糊表述技巧**：无充分证明材料的案件细节简化或不写；不确定时间用「2023年初」类模糊写法，不用不确定的具体日期（新则七点建议）
- **「初步认定」双刃性提示**：限定语「初步认定」保留事实复核空间（降险设计），但对方可能援引主张「贵所自认事实未经最终确认」。应对：①函中事实叙述坚持「经审查属实的证据材料为主」的正面陈述；②后续诉讼中以证据目录+证据本身证明事实，不受函件「初步」措辞束缚；③必要时在特别声明中强化「本函事实认定系基于委托人承诺真实性的材料」

## 三、权利保留三件套（标准原文，逐字套用）

**1. 权利保留条款**（融入律师建议部分）：
> 若贵司未按约付款，委托人将依据《民法典》第五百七十七条、第五百七十九条、第五百八十四条及合同约定，向贵司主张逾期付款利息、资金占用损失及其他违约责任。

**2. 不视为宽容宽限条款**：
> 本律师函不视为委托人对贵司[未及时办理验收确认、未按约付款或其他不当履行行为]的宽容、宽限或权利放弃。

**3. 特别声明条款**（含经办律师联系渠道，律协硬性要求）：
> 特别声明：本律师函所依据的事实及证据系由委托人提供，且委托人已承诺对其真实性、完整性、准确性负责，但并不排除贵司与委托人对客观事实的认知有所出入的可能。贵司如对本律师函涉及事实有所异议，或对问题的解决有其他合理建议，请直接与本律师联系沟通。

## 四、不减损权利清单（起草前逐项核对）

| 检查项 | 规则 |
|--------|------|
| 违约金/逾期损失 | 委托人未明示放弃的，应**一并列入主张**，不得省略（新则七点建议） |
| 违约金计算标准 | 合同有约定标准的，**不得自行降低** |
| 权利处置选择 | 继续履行 vs 解除等择一权利的，**征询委托人决策**，不得擅自主张（上海律协 2021 指引第 16 条意见征询） |

## 五、期限与金额规范

| 项 | 标准 |
|----|------|
| 催告期限 | 「收函之日起五个工作日内」（不写自然日模糊表述） |
| 说明/异议期限 | 「三个工作日内」 |
| 履约催告宽限期 | 金钱债务 ≥15 日（法定解除前置催告场景） |
| 金额 | 精确到分位：X,XXX,XXX.XX 元；千分位分隔；总额与分项勾稽 |

## 七、禁止性语言与去 AI 味（上海指引第 4 条 + 交付形式审查）

- **禁止污辱、谩骂、攻击、恐吓性词语**（违背律师职业素养）
- **不夸大法律后果**（不利后果多角度但不过度）
- **不暗示强制执行力**：禁止「如不履行将强制执行」类表述（律师函无强制执行力）
- 禁用：值得注意的是、综上所述、总而言之、需要指出的是、毋庸置疑
- 禁感叹号；中文全角标点；双引号必须全角弯引号（“”）
- 表格只放结论性事实，分析性文字移出表格
- 律师建议以敬语开头（避免强硬引发反感）：「鉴于双方友好合作关系，本律师现提出以下建议」

## 八、自认/要约/承诺禁区（判例实证——函中表述可能成为对己不利的证据）

| 禁区 | 判例/依据 | 防控 |
|------|----------|------|
| **金额错误构成自认** | 函中债权金额写错，对方回复认可后，超出部分主张可能不被支持 | 金额、日期、合同编号**必须经委托人书面确认**；发现错误**立即书面更正并留存更正记录** |
| **权利放弃表述构成要约** | 「若在一定期限内归还款项则不追究违约责任」= 变更合同的新要约，是对自身权利的放弃 | 涉及权利放弃、债务减免、履行条件变更、和解方案的表述**必须经委托人专项授权**并标注「以最终协议为准」 |
| **不利事实陈述构成自认** | 函中承认对己不利事实，诉讼中难以否认 | 起草时避免陈述于己不利的事实 |
| **签收即自认（对方视角）** | 签收律师函时签字认可内容可能构成自认（《民诉证据规定》第 3 条） | 函末可注明「签收仅代表收到，不代表认可函件内容」；提醒己方委托人审查对方回函/签收单表述后再签收 |
| **侵权定性措辞** | [地区]（2024）：函含负面定性+朋友圈转发=名誉侵权；芜湖（2023）：「无运营资质」=商业诋毁；[地区]（2025）：「已被判决侵权」不实=商业诋毁 | 用「涉嫌侵权」不用确定性定性；引用既往诉讼结果必须准确完整；函件标注「本函仅限收件人使用，请勿扩散」；避免对特定自然人的定性式指控 |
