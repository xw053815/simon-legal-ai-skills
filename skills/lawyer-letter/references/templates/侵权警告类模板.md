# 侵权警告类律师函模板

> **确信度 C**：本类暂无本所实战范本，模板基于通用实务 + 上海律协 2026 指引三段式构建。首次实战使用后必须知识反哺修订本文件。
> **适用场景**：知识产权侵权（商标/专利/著作权/不正当竞争）、名誉侵权、商业秘密侵权等，要求停止侵权并视情况索赔或整改。
> **正文结构**：官方三段式（一、相关事实；二、法律意见；三、律师建议）——上海律协 2026 指引第 12 条。

---

## 结构要点

| 段 | 内容 |
|----|------|
| 一、相关事实 | ①权利基础：权属证明（商标注册证/专利证书/著作权登记/合同权益）；②侵权事实：侵权主体、行为方式、时间、范围、证据载体（公证截图/购买记录/鉴定报告），客观陈述不定性 |
| 二、法律意见 | 引用《商标法》/《专利法》/《著作权法》/《反不正当竞争法》具体条文 + 侵权构成要件比对，阐明法律后果 |
| 三、律师建议 | 敬语开头 → 停止侵权要求（期限+具体行为）→ 赔偿/整改要求 → 不利后果（多角度不夸大） |

## 骨架（差异部分，通用骨架见三段式模板）

**一、相关事实**

1、[权利基础：委托人系第 XX 号《XX》的合法权利人/被许可人，权属证据为[XX]]；
2、[侵权事实：贵司于[时间]起，未经许可[使用/复制/销售]……，相关证据为[公证书编号/购买凭证等]（客观陈述，不用「恶意」「盗版」定性词）]；
3、[损害事实：上述行为已造成委托人[损失概述]（如无独立证据，注明「具体损失正在进一步核定中」）]。

**二、法律意见**

根据《[商标法/专利法/著作权法/反不正当竞争法]》第[XX]条之规定，贵司上述行为已[落入委托人权利保护范围/构成对委托人 XX 权的侵犯]，委托人有权要求贵司承担停止侵权、赔偿损失等法律责任。

**三、律师建议**

1、请贵司于收函之日起[五]个工作日内立即停止[具体侵权行为]；
2、请贵司于收函之日起[五]个工作日内[删除/下架/销毁相关内容或产品]，并书面承诺不再实施类似行为；
3、请贵司于收函之日起[十]个工作日内与经办律师联系，协商赔偿事宜；
4、若贵司未按上述要求履行，委托人将依据[法条]采取包括但不限于提起诉讼、申请行政查处、财产保全等法律措施，届时贵司还须承担相应诉讼费用，并可能影响贵司商业信誉。

## 专属风险点（起草前必查）

| 风险 | 防控 |
|------|------|
| 权利权属瑕疵 | **权属证据先行固定**：发函前核验商标注册证/专利证书/著作权登记在有效期内，权利人名称与委托人一致；被许可人出函须有许可合同+维权授权条款 |
| 过度定性构成商业诋毁/名誉侵权 | 侵权事实只客观陈述（时间+方式+载体），不用「恶意」「盗版」等道德定性词；未经生效裁判不得向第三方散布侵权指控 |
| 侵权事实证据不足 | 关键侵权事实须有公证/时间戳/购买记录等客观证据；仅凭网页截图的，先做证据固定再出函 |
| 赔偿金额张口 | 无损失计算依据时不列具体赔偿金额，只写「协商赔偿事宜」；确需列明的，注明计算依据 |
| 法定前置程序 | 电商平台投诉/行政查处是否需先发函，查证后再定路径 |
