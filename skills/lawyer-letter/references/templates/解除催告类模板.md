# 解除/催告类律师函模板

> **确信度 C**：本类暂无本所实战范本，模板基于通用实务 + 上海律协 2026 指引三段式构建。首次实战使用后必须知识反哺修订本文件。
> **适用场景**：合同解除通知（约定解除权/法定解除权）、履约催告（继续履行前置）。
> **正文结构**：官方三段式（一、相关事实；二、法律意见；三、律师建议）——上海律协 2026 指引第 12 条。

---

## 两个变体（选用其一）

- **变体 A：解除通知**——行使约定/法定解除权，函件到达即解除（《民法典》第 565 条）
- **变体 B：履约催告**——催告继续履行，为后续法定解除或违约主张固定「经催告拒不履行」事实

## 结构要点

| 段 | 内容 |
|----|------|
| 一、相关事实 | 合同签订与履行情况、对方违约事实（客观证据）、催告历史（如有）、解除权触发事实 |
| 二、法律意见 | 解除权依据：约定解除（合同第 X 条）/ 法定解除（《民法典》第 563 条，先经催告的要写明催告经过）；法律后果 |
| 三、律师建议 | 敬语开头 → 解除通知（到达生效）或催告要求（期限+履行内容）→ 后续安排（返还财产/结清款项/移交资料）→ 不利后果 |

## 骨架（差异部分，通用骨架见三段式模板）

**一、相关事实**

[合同名称编号、签订日期、履行情况、对方违约事实（附客观证据：往来函件/验收记录/付款流水）、此前催告情况]。

**二、法律意见**

[变体 A]：贵司的上述行为已符合《[合同名称]》第[XX]条约定的解除条件（及/或构成《民法典》第五百六十三条规定的法定解除事由），委托人有权解除合同。
[变体 B]：根据《[合同名称]》第[XX]条约定及《民法典》第五百七十七条之规定，贵司应当继续履行合同义务并承担违约责任。

**三、律师建议**

[变体 A——解除通知]：
1、依据《[合同名称]》第[XX]条约定（及/或《民法典》第五百六十三条），委托人决定解除与贵司签署的《[合同名称]》（编号：[XX]）；
2、依据《民法典》第五百六十五条第一款，本函到达贵司之日，上述合同解除；
3、请贵司于收函之日起[五]个工作日内[返还财产/结清款项/移交资料]；
4、贵司如对合同解除有异议，可依法请求人民法院或仲裁机构确认解除行为的效力。

[变体 B——履约催告]：
1、请贵司于收函之日起[十五]日内继续履行《[合同名称]》项下[具体义务]；
2、若贵司在上述期限内仍不履行，委托人将依法解除合同，并依据《民法典》第五百七十七条、第五百八十四条主张赔偿损失。

## 专属风险点（起草前必查）

| 风险 | 防控 |
|------|------|
| 解除权不成立即发函 | **解除权成立核验在前**：约定解除查合同条款触发条件是否成就（逐字核对）；法定解除查《民法典》第 563 条要件，迟延履行解除必须先经催告（变体 B 先行） |
| 异议期表述错误 | **不写「如有异议请于 X 日内」**——第 565 条不再设固定异议期，写了反而给对手机会质疑解除生效；标准表述：「可依法请求人民法院或仲裁机构确认解除行为的效力」 |
| 到达证明缺失 | 解除自通知**到达**生效——EMS+面单备注「解除合同通知函」+送达截图是生命线，禁止仅电子邮件发送 |
| 催告期限不足 | 履约催告的合理期限一般不得短于 15 日（金钱债务），过短的期限可能被认定催告无效 |
| 解除后义务漏项 | 解除函必须同步安排返还财产、结清款项、资料移交、保密义务存续等后续事项，漏项会导致履行僵局 |
