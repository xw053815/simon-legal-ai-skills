# 律师函 — 通用三段式模板（上海律协 2026 指引对齐，含占位符）

> 所有类型律师函的骨架。先套骨架再填内容（败笔修正表第 1 条）。
> 结构依据：《上海市律师协会律师办理签发律师函业务操作指引（2026）（试行）》第 11-14 条。
> 占位符用 `[方括号]` 标注，交付前必须全部替换——`view text` 检查无残留。

**一、相关事实**

[经承办律师审查属实的证据材料为主，客观还原事实，不夹杂经验判断/法律认定/价值判断。

**二、法律意见**

[紧扣法律规定及合同约定，三段论演绎推理。
例：由于上述委托人提供的事实，我们认为，根据《中华人民共和国XX法》等法律规定及《XX合同》第X条等约定，贵司XX的情形已构成严重违约/侵权行为，给委托人造成经济损失，委托人有权要求贵司承担【XX】的法律责任。
对争议较大或权力机关尚未认定的事实，不作绝对化结论。]

**三、律师建议**

[敬语开头]：鉴于双方友好合作关系，为妥善解决上述纠纷、避免诉累，本律师提出以下建议：

1、请贵司于收函之日起[五]个工作日内[行为请求]；
2、请贵司于收函之日起[五]个工作日内[金钱请求]；
[有付款前提条件的分期合同，替换第 2 项为以下两项：
2、请贵司于收函之日起[五]个工作日内向委托人支付条件已成就的款项[XX]元；
3、请贵司于收函之日起[三]个工作日内就其余款项的支付条件成就情况向委托人作出书面说明；]
[尾项：不利后果警示，多角度不夸大]：若贵司未按[约/本函要求]履行，委托人将依据《民法典》第[XX]条、[第XX条]及[合同约定]，向贵司主张[后果范围——无约定违约金时只写「逾期付款利息、资金占用损失及其他违约责任」]。届时贵司不仅需支付上述款项，还须承担相应违约责任及诉讼费用，并可能影响贵司企业信用。

[权利保留条款 + 不视为宽容宽限条款 + 特别声明——三件套见措辞库]

## 使用规则

| 项 | 规则 |
|----|------|
| 骨架先行 | 先套本骨架再填内容，不得先写正文后补格式 |
| 委托声明三部分 | 委托来源（客户委托律所→律所指派律师）+ 委托事项（案由参考）+ 保留条款（材料来源是客户）——上海指引第 11 条 |
| 正文三段式 | 一、相关事实；二、法律意见；三、律师建议——上海指引第 12 条，标题不可省略 |
| 律师建议三段 | 敬语开头 + 提出要求（期限+请求）+ 不利后果（多角度不夸大）——上海指引第 13 条 |
| 常法 vs 专项委托 | 常法客户用「作为……的常年法律顾问」；专项委托用「接受……的委托」 |
| 函告事项顺序 | 行为请求在前、金钱请求在后、后果预告收尾；有付款前提条件的合同必须启用「分期分口径」占位符（败笔表第 5 条），禁止一刀切全额立即到期 |
| 律所名称核验 | 套用前核验律所执业名称与委托人委托关系表述（以执业许可证登记名称为准） |
| 定稿日期 | 送签章的定稿日期留白（「[YYYY]年[M]月　　日」），由签署日填写 |
| 篇幅 | 1-2 页；超出则删套话、压缩分析，不删事实支撑点 |
