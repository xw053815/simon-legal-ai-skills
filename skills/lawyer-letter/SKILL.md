# 律师函 — 全流程铁律

> 本技能是律师函业务的**全流程铁律**：定义 → 门禁 → 类型选型 → 起草 → 措辞分寸 → 排版 → 委托人确认 → 发送留证 → 归档跟进。
> 实战来源：某科技公司常法项目致某软件公司催款律师函（[年月]，v01→v05 共 6 稿 + 指导律师确认定稿，已实际发出并留证）。
> 规范依据：上海市律师协会《律师办理签发律师函业务操作指引（2026）（试行）》（2025-12-30 通过，试行一年）为最高优先级；辅以杭州律协、广东律协、南京律协、厦门律协指引。

## §0 律师函的定义与性质（以始为终——先定义，再写作）

> **本技能的核心立场：律师函的“定义”决定一切。** 结构、逻辑、措辞、排版全部由定义推导——先搞清楚律师函是什么、不是什么，才能写出合格的律师函。

### 0.1 定义（上海律协 2026 指引第二条，权威定义）

> **律师函是律师事务所基于委托人的委托，指派承办律师针对特定法律事务，根据委托人的陈述和提供的书面材料，结合法律规定向律师函相对方披露、分析、告知法律后果，代委托人提出要求、声明事实、作出意思表示、实施民事法律行为，或实现当事人其他合法目的的专业文书。**

定义拆解（七要素，逐项落实为写作动作）：

| 要素 | 含义 | 写作落实 |
|------|------|---------|
| ①律师事务所 | 委托关系主体是律所，不是律师个人 | 落款律所全称+公章；开篇不得暗示律师个人接受委托 |
| ②基于委托 | 有委托合同/授权委托书，范围明确 | G0 授权核验；委托声明写明委托来源 |
| ③指派承办律师 | 承办律师以律所名义承办 | 开篇写「指派[XX]律师」；落款承办律师签名 |
| ④针对特定法律事务 | 一事一函，不泛泛而谈 | 委托事项参考《民事案件案由规定》确定（上海指引第 11 条） |
| ⑤根据委托人陈述和书面材料 | 事实来源是委托人，律师有审查义务 | 限定语「根据委托人陈述及提供材料」；事实审查（G1） |
| ⑥结合法律规定 | 法律分析有依据，不凭空发挥 | 引用具体法条+合同条款；三段论演绎 |
| ⑦披露、分析、告知、提出要求/声明/意思表示 | 功能性目的 | 三段式正文：事实→法律→律师建议 |

### 0.2 法律性质与作用（律师函能做什么）

| 作用 | 法律依据/效果 | 写作落实 |
|------|-------------|---------|
| 催告/警告 | 要求履行义务、停止侵权 | 函告事项明确期限+行为/金钱请求 |
| **中断诉讼时效** | 《民法典》第 195 条，催款类核心功能 | G1 时效核验；送达凭证是中断时效证据 |
| **行使形成权** | 解除通知（《民法典》第 565 条）、催告等 | 解除类函件写明「本函到达之日合同解除」 |
| 法定前置程序 | 部分场景发函是诉讼/仲裁前置条件 | 发函前查证是否法定前置 |
| 证据固定 | 证明相对方知悉事实、经催告仍不履行 | 全程留证：EMS+存根+送达截图+邮箱记录 |
| 促成和解 | 降低诉讼成本 | 律师建议部分可提协商口径 |

### 0.3 边界（律师函不是什么——必须克制）

- **不是判决书**：无强制执行力，**禁止暗示律师函本身具有强制执行效力或超越法律授权的表述**（iCourt 指引）
- **不是法律意见书**：篇幅 1-2 页，事实+立场+要求，不展开长篇法律论证
- **不得过分夸大法律后果**（上海指引第 4 条）：不利后果部分应多角度（法律/商业/信誉）但不夸大
- **不得使用污辱、谩骂、攻击、恐吓等词语**（上海指引第 4 条）
- **不得以律师函名义炒作案件、向不特定对象推广宣传**（上海指引第 4 条）
- **不代替委托人作权利选择**：涉及权利处置的选择（如继续履行 vs 解除），征询委托人决策（上海市律协 2021 年《（试行）律师签发律师函业务操作指引》第 16 条意见征询——旧指引，非 2026 指引条文）

**侵权诉讼边界（判例实证，六案）**——律师函措辞与传播范围是名誉权/商业诋毁的过错边界：

| 判例 | 认定 | 实操启示 |
|------|------|---------|
| [地区]法院（2024）微信朋友圈转发律师函案 | 函含对员工道德素养负面定性+公司组织员工朋友圈转发 → 名誉侵权成立 | **传播范围+定性措辞双高=侵权**；函件标注「本函仅限收件人使用，请勿扩散」 |
| [地区]法院（2023）向竞争对手客户发函案 | 称原告「无运营资质」属编造传播虚假/误导信息 → 商业诋毁，判赔 3 万 | **向第三方（客户/平台）发函措辞若含贬损推断 → 从维权变侵权**；限客观事实+风险提示 |
| [地区]中院（2025）专利维权函案 | 称「多次被判决侵权」但此前诉讼已认定不侵权 → 未全面披露+不实陈述 → 商业诋毁 | **引用既往诉讼结果必须准确完整**；未决/败诉事项不得包装成「已被判决侵权」 |
| [地区]测绘院诉红邦/中盛律所案（二审） | 「抄袭」「侵犯著作权」措辞有争议但属专业法律判断 → 不构成商业诋毁 | **反向边界**：涉及专业法律判断的权利主张，法院对措辞瑕疵有一定容忍度；但「涉嫌侵权」仍比确定性措辞更安全 |
| 安徽首例状告律师案（[地区]再审） | 律师函指向具体个人（要求单位处理某员工）致其被免职 → 省检抗诉缠讼多年 | **函件尽量避免对特定自然人的定性式指控** |
| [地区]法院驳回名誉权案 | 单线送达+不公开+措辞克制 → 不构成侵权 | **安全三支柱**：单线送达、不公开扩散、措辞克制——突破任一条风险即上升 |

**自认/要约/承诺禁区（判例实证）**——函中表述可能成为对己不利的证据：

- **金额错误构成自认**：函中债权金额写错，对方回复认可该金额后，后续主张超出部分可能不被支持（实务分析）；**金额、日期、合同编号必须经委托人书面确认**
- **权利放弃表述构成要约**：「若在一定期限内归还款项则不追究违约责任」= 变更合同的新要约，是对自身权利的放弃；涉及权利放弃、债务减免、履行条件变更、和解方案的表述**必须经委托人专项授权**并标注「以最终协议为准」
- **不利事实陈述构成自认**：函中承认对己不利事实，诉讼中难以否认；**起草时避免陈述于己不利的事实**
- **错误函件处理**：发现错误应**立即书面更正并留存更正记录**

### 0.4 适用与禁止范围

**适用（上海指引第 3 条）**：①答复来函；②要求相对方履行金钱给付义务、交付财产、为或不为一定行为；③代委托人通知解除合同、中断诉讼时效等改变法律状态；④其他合理情形。

**一般不宜出具**（上海指引第 3 条）：
- 刑事案件（除刑事自诉、刑事和解等当事人可自行处分权利的情形）
- 行政案件中需向行政机关申请、申诉、交涉的（应改其他公文方式）

**拒绝出函情形**（新则七点建议 + iCourt 指引，独立于上海指引）：
- 涉及人身关系变更（婚姻解除、收养等）
- 涉嫌违法犯罪活动（“套路贷”、涉黑涉恶）
- 存在利益冲突、虚构捏造事实、委托人坚持违法或明显不合理要求、免费出函请求——**敢于说不，书面记录拒绝理由**

### 0.5 工作原则（上海指引第 4 条，四条）

1. **以事实为依据、以法律为准绳**，客观表达意见
2. **准确运用法律语言**，不得使用污辱、谩骂、攻击、恐吓等词语，不夸大法律后果
3. **保密义务**：国家秘密、商业秘密、个人隐私，根据委托人要求保密
4. **不得违规炒作/推广**：不以律师函名义炒作案件，不向不特定对象业务推广

## §2 发函前双门禁

### G0 授权核验（缺任一项 = 不得出函）

- [ ] 与律所签订**法律服务合同**，委托事项明确含签发律师函；后补的签补充协议/谈话笔录（上海指引第 5 条）
- [ ] 签订《授权委托书》**一式三份**：一份随律师函寄送收件人，一份承办律师归档，一份交委托人（上海指引第 6 条）
- [ ] 履行**利益冲突审查、统一收案**手续（上海指引第 5 条）
- [ ] OA 系统出函申请提交并截图归档（存 `02_scratch/OA页面核对/`）
- [ ] 常法客户须核验年度顾问合同是否覆盖本次出函事项
- [ ] 文号「（[YYYY]）XX律函字第[XX]号」申请取得后回填
- [ ] **拒绝出函情形检查**（上海指引第 7 条 + 新则七点建议）：利益冲突 / 涉黑涉恶“套路贷” / 虚构捏造事实 / 委托人坚持违法或明显不合理要求 / 免费出函请求——命中任一项，**敢于说不**，书面记录拒绝理由

### G1 事实核验（强制产出事实底稿）

按 `references/事实底稿模板.md` 产出事实底稿（底稿本身四节结构：已核对/待核验二分、文书同步口径、轻量裁判视角核验、附证据清单）。G1 共 10 项核验，逐项落实：

1. **已核对事实 / 委托人陈述或待补充核验事实 二分**——没证据的只是声称，不是事实
2. **关键事实 ≥2 来源交叉核对**：合同编号、金额、日期、主体名称、验收/履行状态
3. **事实审查六要素**（上海指引第 10 条 + 南京/厦门指引）：①主张要求名称准确、范围明晰、内容固定 ②委托人对其主张切实拥有合法权利 ③第三方与委托人关系 ④第三方是否存在违约/侵权及具体事实 ⑤第三方可能承担的法律责任 ⑥证据材料能否支持律师意见
4. **引用法条现行有效性核验**：走全国人大法律法规数据库或北大法宝/元典（某科技公司做法：核验《民法典》第 577/579/584 条）
5. **诉讼时效核验（催款/债权类必查）**：比对债务到期日与时效届满日。临近或已逾时效的，函件策略须先经指导律师评估（发函可中断时效，但已逾时效的债权出函反而暴露己方怠于行权）
6. **合同通知送达条款核验**：查合同是否约定通知送达地址、电子送达方式、拒收/退件视为送达条款。有约从约——向约定地址发函并留存凭证；无约的按注册地址/实际经营地双地址寄送
7. **相对方主体存续核验 + 收件人身份核验**：经企查查/天眼查核验相对方存续状态、有无更名/注销/迁址；**收件人姓名/名称经系统网站核验，身份信息保存为 PDF 打印归档**（上海指引第 10 条）
8. **付款前提成就状态及证据归属方标注（有前提条件的合同必查）**：区分「前提成就在我方可证」（如里程碑签收）与「成就证据在对方侧」（如最终客户付款——我方无法独立核实）。后者函件口径为「要求对方限期书面说明条件成就情况」，不得在事实节写成「条件未成就」
9. **谈话笔录（必要案件强制）**：仅委托人陈述、无客观证据的，必须制作谈话笔录（真实性承诺、风险提示、签字盖章）（上海指引第 8 条）
10. **轻量裁判视角核验**：类案检索 1-3 条，检验催告口径稳健性（某科技公司：北大法宝 HTTP 524 失败 → 切换法睿，取（YYYY）粤XX民终XXXX 号「付款方怠于向最终客户催收视为条件成就」支撑分期催告口径）。检索工具失败要记录断点并切换路径，不得跳过

底稿「本轮文书同步口径」节：标明以哪稿为基础、保留哪些委托人确认点（某科技公司保留「发票材料待补充核验」「无固定违约金标准」两个标黄点）。

## §3 律师函类型矩阵

| 类型 | 结构要点 | 核心措辞 | 专属风险点 |
|------|---------|---------|-----------|
| **催款催收类**（某科技公司标杆，确信度 A） | 三段式：①相关事实（含材料清单+付款节点表）→ ②法律意见 → ③律师建议（催付+后果预告） | 「收函之日起五个工作日内」「条件成就的一并支付、尚未成就的于三个工作日内书面说明」 | 付款前提条件未成就时不得直接认定全部到期；前提成就证据在对方侧的，催说明不催付款；金额精确到分位并勾稽；无约定违约金时只保留利息/资金占用损失口径 |
| **侵权警告类**（确信度 C，待实战反哺） | 官方三段式：①相关事实（权利基础+侵权事实）→ ②法律意见（侵权构成+责任）→ ③律师建议（停止侵权+赔偿/整改要求+后果预告） | 「立即停止……行为」「保留追究法律责任的权利」 | 权利权属证据先行固定；避免过度定性构成商业诋毁或名誉侵权 |
| **解除/催告类**（确信度 C，待实战反哺） | 官方三段式：①相关事实（合同依据+解除事由）→ ②法律意见（解除权成立依据）→ ③律师建议（解除通知+后续安排） | 「本函到达之日合同解除」（《民法典》第 565 条）；异议表述「可依法请求确认解除行为的效力」——**不写「如有异议请于 X 日内」**（第 565 条不再设固定异议期，写了反而质疑解除生效） | 法定/约定解除权成立核验在先；异议期表述准确 |
| **声明澄清类**（确信度 C，待实战反哺） | 官方三段式：①相关事实（澄清背景+客观事实）→ ②法律意见（权利状态/立场依据）→ ③律师建议（声明+权利保留） | 「特此澄清」「本函不构成对任何权利的放弃」 | 克制定性：陈述事实，不评价对方动机 |

各类型详细模板见 `references/templates/`。**侵权/解除/声明三类无实战范本，首次实战使用后强制知识反哺修订本表。**

## §4 措辞分寸十三条（核心章节）

| # | 规则 | 说明与出处 |
|---|------|-----------|
| 1 | **限定语强制** | 事实叙述须注明「依据委托人陈述及提供材料」；事实节标题统一为「一、相关事实」（上海指引第 12 条） |
| 2 | **待核验事项就地标注** | 未核验材料在函中注明，不得写成既成事实（某科技公司 v04/v05 对发票材料的处理） |
| 3 | **否定性事实用正面句式** | 验收报告对方签章栏空白 → 写「现有材料证明贵司尚未完成项目签章验收」，不用「本函不表述为……」的元叙述（v01→v03 修正） |
| 4 | **措辞降险体系** | 合同未约定明确期限时：「逾期验收」→「未及时办理验收确认/未在本函期限内完成验收确认」；「逾期付款」→「未按约付款」；兜底用「其他不当履行行为」替代「其他违约行为」（v05 修正成体系） |
| 5 | **事实可以少写不写，但不可失实** | 无充分证明材料的案件细节尽量简化或不写；不确定的时间用模糊表述（「2023年初」而非不确定的具体日期）（新则七点建议） |
| 6 | **豁免条款备用** | 证据不充分时，除限定语外可加「以上事实正在进一步调查取证中」（上海律协 2021 指引第 10.2 条） |
| 7 | **权利保留三件套（每函必备）** | ①权利保留条款（依据《民法典》具体条文+合同约定主张）；②不视为宽容宽限条款：「本律师函不视为委托人对贵司……的宽容、宽限或权利放弃」；③特别声明条款（含经办律师联系方式，见速查卡原文） |
| 8 | **不减损委托人任何权利** | 委托人未明示放弃的违约金/逾期损失等应一并列入主张，**不得省略**；合同约定了违约金标准，**不得自行降低标准**（新则七点建议） |
| 9 | **不代替委托人作选择** | 涉及权利处置的选择（继续履行 vs 解除等），须提示委托人并征询决策，不得擅自主张（上海律协 2021 指引第 16 条） |
| 10 | **期限与金额表述** | 催告期限「收函之日起五个工作日」；说明/异议期限「三个工作日」；金额精确到分位（X,XXX,XXX.XX 元）、千分位分隔、总额与分项勾稽（某科技公司：X,XXX,XXX = X,XXX,XXX + X,XXX,XXX） |
| 11 | **禁止性语言清单** | 禁污辱/谩骂/攻击/恐吓词；禁「值得注意的是」「综上所述」；禁感叹号；禁暗示强制执行力；对未决事实不作绝对化、结论性认定（区分「委托人主张」与「法律认定」） |
| 12 | **称谓与标点** | 致函对象称「贵司」、己方称「委托人」（禁「我司/我方」）；中文全角弯引号（“”） |
| 13 | **自认/要约/承诺禁区（判例实证）** | 函中金额/事实错误构成自认、权利放弃表述构成要约、不利事实陈述构成自认——金额日期合同编号必须经委托人书面确认；权利放弃/减免/条件变更表述须专项授权并标「以最终协议为准」；避免陈述于己不利事实；错误函件立即书面更正留痕（详见速查卡第八节） |

「禁用 → 推荐」对照速查卡见 `references/措辞库_分寸规则速查.md`。

## §5 败笔修正表（某科技公司 v01→v05 实战提炼，13 条）

> **适用前提**：败笔表是判断依据，不是填空模板。主要适用有付款前提条件的分期合同催款场景，其他类型参照精神不照搬条文。

详见 `references/败笔修正表_实战案例v01-v05.md`。核心五条（高频踩坑）：

1. **骨架先行**：首稿必须先套函件骨架（信头/文号/致/委托声明/正文三段式）再填内容，不得先写正文后补格式（v01 裸正文 → v02 补骨架）
2. **事实叙述第一节固定来源基础**：材料清单+限定语，为事实认定建立来源基础，同时向对方展示证据掌控（v03 起增加）
3. **分期分口径催告**：有付款前提条件的合同，禁止「一刀切全额立即到期」；条件成就的催付、未成就的要求书面说明（v05 定稿口径）
4. **定性动词降级**：合同未约定期限时禁用「逾期」定性（v05「逾期验收」→「未及时办理验收确认」）
5. **精简不删事实支撑点**：精简稿删套话（执业资格自述等），但履行事实证明必须保留并具体化到客观记录（验收时间地点、聊天记录）（v04→定稿回摆）

## §6 正文结构（上海律协 2026 指引对齐）

### 6.1 三段式总结构

| 段 | 标题（上海指引第 12 条） | 内容 |
|----|------------------------|------|
| 一 | **相关事实** | 经承办律师审查属实的证据材料为主；未充分核实的标「委托人陈述事实如下」；只还原客观事实，不夹杂经验判断/法律认定/价值判断 |
| 二 | **法律意见**（或「法律分析及法律后果」） | 紧扣法律规定+合同约定，三段论演绎推理，言之有据 |
| 三 | **律师建议**（或「解决问题的方法及建议」） | 敬语开头 + 提出要求 + 不利后果（上海指引第 13 条，见 6.3） |

> **与某科技公司范本的关系**：某科技公司定稿的三段（材料清单/基础法律事实/函告事项）是催款场景的实践变体——材料清单并入「一、相关事实」的引子，函告事项即「三、律师建议」。实践变体与官方三段式不冲突，但**新函一律按官方三段式组织**，某科技公司变体作为催款类范例保留在模板中。

### 6.2 委托声明（函件开篇，上海指引第 11 条三部分）

1. **委托来源**：表明律师介入的正当性（客户委托律所→律所指派律师，避免《律师法》第 40 条第 1 项私自接受委托之嫌）
2. **委托事项**：开宗明义，参考《民事案件案由规定》确定
3. **保留条款**：材料来源是客户，律师在客户提供资料基础上作出认定与分析

示例：`XX 律师事务所接受 XXX 公司（以下简称“委托人”）的委托，指派 XX 律师，就双方 XX 纠纷一案，根据委托人所提供的案件材料，依据事实与法律向贵司致函如下：`

> 上海指引第 9 条：承办律师可对拟出函涉及事实发表法律意见、提供专业建议，合法合规前提下按委托人意愿完成起草；第 10 条：向与纠纷无直接联系但确有必要的主体抄送的，应在正文中论证必要性。

### 6.3 律师意见三段式（上海指引第 13 条）

1. **敬语开头**：避免过于强硬引发反感。如「鉴于双方友好合作关系，本律师现提出以下建议」「为弥补委托人损失，妥善解决上述纠纷、避免诉累，本律师提出以下建议」
2. **提出要求**：写明期限+行为/金钱请求。如「现委托人善意催告贵司履行合同义务，请于收到本函后五个工作日内支付全部尾款及追加费用共计 XXX 元」
3. **不利后果**：多角度警示（法律/商业/信誉），不夸大。如「贵司逾期不支付上述款项的，委托人将依照《XX 法》第 XX 条提起诉讼。届时贵司不仅需支付上述款项，还须依照《XX 合同》第 XX 条支付违约金，承担诉讼费用，并可能影响贵司企业信用」

### 6.4 函件尾部四要素（上海指引第 14 条）

| 要素 | 要求 |
|------|------|
| 落款 | 律所名称 + 承办律师姓名（非执业人员不得署名）+ 签发日期；加盖律所公章 + 承办律师亲笔签名（或律师章） |
| 寄送方式 | 写明函件送达形式：「本函以 EMS 及电子邮件（收件邮箱：XXXXX）的方式送达贵司」 |
| 联系方式 | 承办律师姓名 + 联系电话（固定+移动） |
| 附件 | 授权委托书、和解协议、询证函等，写明「附《授权委托书》一份」 |

### 6.5 抬头邮寄信息块（新则七点建议，留证事半功倍）

函件抬头（致送对象后）载明邮寄信息，便于证明邮寄地址、规避底单地址加密风险：

```
本函通过 EMS 及电子邮件发送

致：[收件人全称]
邮寄地址：[XX]
收件人：[XX]
联系电话：[XX]
电子邮箱：[XX]
```

### §8.5 形式要件（用印与签字规范——诉讼中常被对方质疑真实性的攻击点）

## §10 发函后跟进（期限届满动作树）

| 对方反应 | 动作 |
|---------|------|
| 全部履行 | 归档结案，书面告知委托人 |
| 部分履行/提出履行计划 | 评估是否接受；接受则签书面补充确认，不接受则书面拒绝并保留权利 |
| 书面异议 | 转事实底稿复核异议依据；成立则修正口径，不成立则复函驳复（限期回复）；相对方提供证据证明委托人隐瞒事实/提供虚假信息的，向委托人反馈核实并商讨下一步（上海指引第 18 条） |
| 无回应 | 期限届满次日提醒委托人；衔接「批量催收」skill 的「催告函→律师函→支付令→诉讼」链条，催收类无回应即升级支付令/诉讼评估 |

## §11 归档规范（上海指引第 19 条，八项）

完成签发律师函业务后立卷归档，交由律所妥善保管：

1. 法律服务合同（+收费发票，单项业务适用）
2. 委托人提供的证据材料及相关工作底稿（含事实底稿）
3. 律师函最终稿（定稿）
4. 律所审批材料（含 OA 出函申请截图）
5. 邮寄底单及回执（EMS 详情单原件、签收回执、妥投查询打印件）
6. 律师函签收情况材料（送达截图/代收人信息）
7. 谈话笔录（如制作）
8. 授权委托书（归档联）

存放位置：`03_output/` 归档联 + 律所 OA 系统案卷归档。

## §13 对抗式审查（定稿前强制执行）

三方视角，任一 block 不放行：

| 视角 | 角色 | 攻击点 |
|------|------|--------|
| 我方 | 经办律师 | 定义七要素是否落实、授权要件是否完备、事实二分是否清晰、法条是否现行有效 |
| 对方 | 对方律师 | 措辞定性是否有抗辩口（「逾期」类定性、全额到期口径）、条件未成就款项是否被过度催告、事实认定是否有证据缺口 |
| 裁判 | 法官/仲裁员 | 类案口径稳健性、请求是否具有可执行性、函告事项与后续诉讼主张是否自洽（时效中断证据链是否完整） |

检索路径失败必须记录断点并切换（内置 WebSearch/Tavily → WebFetch → 法律数据库 MCP），不得在失效工具上空转。
